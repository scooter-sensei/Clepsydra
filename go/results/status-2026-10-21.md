## Decisions

**Protocol (committed):** a hold counts on the stripe of the tag in the word1 its CAS takes; claim stripes stay by fingerprint. A count's CAS is checked against word0 after it, and a foreign word0 is resolved by word1's tag once any hold is over. A stale hot slot resets under realign's hold.

**Method (additions):** check a fix against an exact invariant as well as the contract's bound (the fuzzer and the soak check only `Upper ≥ truth`; the racy tests caught the double count). Model the code's loads one for one: a model that waited on one read and decided on another found a race the code doesn't have. Prior art: MemC3's optimistic cuckoo hashing validates lock-free reads with key-striped version counters but runs one writer under a global lock, so its displacing writer always knows the key it moves; with lock-free multi-writer hand-overs only the value a CAS took identifies the key (A28).
