## Decisions

**Method**
- One change per commit, each with a test that fails before and passes after (performance changes: an interleaved A/B instead).
- Deterministic records are regenerated only for deliberate behaviour changes, and the commit says which. This session regenerated them once (395f738: Count values only, conformance vectors included, so every port must follow).
- Historical experiments keep the configuration they were recorded with.
- Race tests, repeated runs and a soak campaign are required before closing a concurrency claim.
- Speed is measured as A/B ratios on one host, arms interleaved; absolute times are reported with the host named.
- Experiments run env-gated in exported trees (`git archive HEAD`), never in the repo; adopted or rejected, the variant is kept as a patch in `verify/experiments/` with a README row.
- Validation that needs git history (`replay.sh`, `regression --full`) runs in a WSL clone. A worktree created from Windows has a `D:/` gitdir that WSL's git can't read.

**Taken this session**
- `Upper` with the overflow table off: documented, not changed. A key that comes back after its history was lost reads low without a flag; `Lost()` is the signal (X32). The fuzzer accepts such lows only within a horizon of a loss.
- The fuzzer checks the contract with `SpillMin: 1` (no shedding), like the soak, and counts the documented exceptions instead of failing on them.
- ConstantTime pads end at a random point over 128 ns (64 ns per call). 64 ns left a residual leak; the leak scales with (dither mod clock-read period)/dither.
- The newest bucket's last event counts whole in `Count` (velocity 0.0807 → 0.0779, VelocityCount +4% by minimum). The binomial-median estimator (0.0776) was not worth its cost.
- The cuckoo search loads one candidate's four next lines together. Loading a whole level at once, and huge pages, are declined on this host's evidence (S42, S43).
- `verify/replay.sh harness` watches every library file, not just `filter.go`/`register.go` (X31).
