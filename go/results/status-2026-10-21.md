## Decisions

**Protocol (uncommitted, A32):** a hot history that leaves for the overflow table closes its entry; a touch that counts by identity must not outlive its history's place in the table or stash.

**Method (additions):**
- Write the adoption rule before the readings (`preregister.md`).
- A failure found while testing a variant is rerun on HEAD and older trees before it is blamed on the variant. E21's case 9787 was HEAD's.
- Export the whole tree (`go` and `spec`) for suite checks.
- Small tables matter: case 9787's 104 slots made evictions of hot keys common.

**Prior art:** for the cost of LOCK CMPXCHG16B on Zen 2, no measured figure was found (uops.info lists LOCK CMPXCHG at 17–19 cycles on Intel cores; LLVM's scheduler notes give ~32–38 for CMPXCHG16B, microarchitecture unnamed). E21's readings are this host's.

**Host**:
- Run WSL work through script files (`MSYS_NO_PATHCONV=1 wsl bash -lc 'bash "/mnt/.../x.sh"'`): inline `$VAR`s and `;` are split or expanded before bash sees them.
- `-race` needs `CGO_ENABLED=1 CC=$HOME/bin/zcc GOFLAGS=-ldflags=-linkmode=external`.
- Python isn't on the Windows side; use WSL's.
- Don't edit a queue script while bash runs it.
- `pkill -f PATTERN` also kills the shell that runs it when its own command line matches: put it in a script whose path doesn't.
- A queue waits on `pgrep -f "[q]N.sh"`, which any process whose command line contains `qN.sh` satisfies. `rerun-q2.sh` and its kin are named that way on purpose, so later queues wait for them.
- In Go, `1<<tagBits-1<<36` is `(1<<tagBits) - (1<<36)`: parenthesize masks before shifting them.
